# Flappy Ten

A small Flappy Bird style desktop game written in Java (Swing). Fly the bird through **10 pillars** to win.
All graphics are simple flat shapes, so no image files are needed.

## Controls
| Key | Action |
|-----|--------|
| SPACE / UP arrow / mouse click | Flap (and start / play again) |
| P | Pause / continue |
| A | Autopilot demo mode |
| ESC | Quit |

## Run it
1. Install Java 8 or newer (JRE or JDK).
2. Double-click `FlappyTen.jar`, or run: `java -jar FlappyTen.jar`

## Build from source
```
javac FlappyTen.java
java FlappyTen
```

## Features
- 10 numbered pillars, win screen after the last one
- Score, "Pillars: x / 10" counter and best score (saved in your home folder)
- Menu, pause, game over and win screens
- Autopilot demo mode
